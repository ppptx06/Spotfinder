## 📱 Дизайн-система & UI/UX
- **Apple Human Interface Guidelines (HIG)**:
  - Эффект матового стекла (`apple-glass` с `backdrop-filter: blur(24px)`).
  - Интерактивная плавающая шторка (`BottomSheet`) с поддержкой жестов разворачивания.
  - Нативная нижняя панель навигации (`TabBar`) с тактильным откликом Haptic.
  - Сегментированные переключатели категорий (`SegmentedControl`).
  - Оптимизация под экраны iPhone/Android (`viewport-fit=cover`, отступы Safe Area).

## 🗄️ База данных и ERD (Table-Per-Type)
- **Супертип `User`** и подтипы:
  - `Student`: Вуз (AITU, NU, ENU), специальность, верификация Student ID, стиль учёбы.
  - `RemoteWorker`: Компания, сфера, график работы.
  - `HighSchoolStudent`: Школа (РФМШ, НИШ, БИЛ), класс.
- **Супертип `StudySpot`** и подтипы:
  - `Library`: Зона абсолютной тишины, бронь книг, открытый доступ, этажность, принадлежность кампусу.
  - `Cafe`: Наличие розеток, средняя стоимость кофе, правило обязательного заказа, меню еды.
  - `StudyRoom`: Вместимость, бронирование, маркерная доска, проектор, почасовая ставка.
- **Инфраструктурные метрики**:
  - `WifiInfo`: Скорость в Мбит/с, тип защиты сети, рейтинг качества.
  - `Outlets`: Тип (EU 220V, Type-C), количество, доступность, рабочее состояние.
  - `Seating`: Занятость мест в реальном времени (`AvailableSeats` / `TotalSeats`).
  - `NoiseLevel`: Уровень в децибелах и категория (`SILENT`, `QUIET`, `LIVELY`).

## 🚀 Запуск проекта

1. **Установка зависимостей:**
   ```bash
   npm install
   ```

2. **Генерация Prisma Client:**
   ```bash
   npx prisma generate
   ```

3. **Запуск dev-сервера:**
   ```bash
   npm run dev
   ```

4. Откройте в браузере: [http://localhost:3000](http://localhost:3000)
   Для мобильного режима нажмите `F12` -> переключитесь на устройство **iPhone 14/15 Pro**.
